# Bundled game licensing

The bundled library is generated from 50 pinned Homebrew Hub entries at commit `50293559a496a3e20382fbf6a2e84b70ec622f88`.

Each `games/manifests/*.json` records the upstream title, declared game license, upstream repository when supplied, exact Homebrew Hub metadata path, exact ROM path, byte size and SHA-256 identity.

The release validator accepts only the permissive license declarations currently used by the bundle: MIT, Zlib/ZLib, and BSD-3-Clause. The library does not contain commercial Nintendo ROMs.
